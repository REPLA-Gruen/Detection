# CCBRE Oct-26 auditor v1.7.1 — overlay correction and secondary verification

This release retains the v1.7 numeric audit and July/October class-reconciliation methodology. Changes relative to the frozen v1.7.0 are limited to the EXIF display-frame preview overlays, a truthful version identifier and additional independent read-only checks. Both v1.7.0 and v1.7.1 source releases should be archived under different names.

## Why this patch exists

The `figures/04_*_box_overlay_samples.jpg` sheets generated by v1.7.0 mistakenly transformed YOLO boxes from an encoded coordinate frame after rotating the photographs. Review of EXIF comparison sheets instead favors the display-frame interpretation. The earlier sheets, as well as the preview section of `Dataset_Audit_Report.html`, are **superseded**. Other figures, CSVs, JSONs, duplicate records and grouped populations were unaffected. Formal human sign-off for the 30-image EXIF ledger remains outstanding.

.\RUN_VERIFY_SECONDARY.ps1 -Analysis "C:\Hadi\Foreign_Material\Data\Ours\Oct-26\Analysis_v1.7" -ExpectedSnapshot -OutputJSON "C:\Hadi\Foreign_Material\Data\Ours\Oct-26\SECONDARY_VERIFICATION_v17.json"

The original verifier produces the previous 56 output-consistency checks. The new secondary verifier explicitly recomputes earliest, latest, maximum-box and minimum-box annotation selections, 1,250 mapped-positive image outcomes, pooled object IoU and the strict-group novelty population, with 30 additional checks against this frozen snapshot. For changed datasets omit `-ExpectedSnapshot` and adapt frozen expected values before accepting a new release.

## Correct the legacy sample overlays WITHOUT re-running the full audit

First COPY `Analysis_v1.7` to `Analysis_v1.7_overlay_corrected` so that original evidence remains immutable. In the copied directory execute:

```powershell
py -3 .\refresh_preview_overlays.py `
  --dataset "C:\Hadi\Foreign_Material\Data\Ours\Oct-26\Raw" `
  --analysis "C:\Hadi\Foreign_Material\Data\Ours\Oct-26\Analysis_v1.7_overlay_corrected"
```

The utility updates just the two `04_*` JPEG previews. It preserves their original versions as `*_LEGACY_ENCODED_FRAME.jpg`. The existing HTML report uses relative links to those JPEGs and automatically shows the corrected previews. This utility requires the original high-resolution photographs, which were **not** included in the uploaded analysis archive. Neither this release package nor the existing attached Analysis_v1.7 zip should be described as having regenerated the previews already.
